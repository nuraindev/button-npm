# hello-world-button

A simple blue button React component that displays "hi" and logs "hello world" to the console when clicked.

## Installation

```bash
npm install hello-world-button
```

**Peer dependencies:** React 17+ and ReactDOM 17+ must be installed in your project.

## Usage

```jsx
import { HellowWorldButton } from "hello-world-button";

function App() {
  return <HellowWorldButton />;
}

export default App;
```

The button renders with a blue background, white text, and rounded corners. Clicking it logs `"hello world"` to the browser console.
